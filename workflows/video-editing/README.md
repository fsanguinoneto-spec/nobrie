# Video Editing Workflow

## Current maturity
Future-facing workflow. Automatic editing is not yet a production system.

## Intended flow
`raw video → classify creative type → retrieve validated patterns → retrieve visual/editing rules → produce or guide edit → validate → consolidate learnings`.

## Guardrail
Only promote repeated, validated evidence into reusable editing rules. Preserve the distinction between observation, hypothesis, recurring pattern, validated pattern, and creative rule.
