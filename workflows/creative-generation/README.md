# Creative Generation Workflow

## Inputs
Use the minimum packet needed: brand context + product context (when relevant) + creative/marketing profile + validated creative patterns + the requested channel/format reference.

## Rules
- Do not invent validated patterns.
- Distinguish brand rules from creative-performance learnings.
- Do not convert a single winning example into a universal rule.
- Respect Nobriê visual identity and voice.
- If an offer is used, distinguish explicit approved offers from general brand rules.

## Output
Produce the requested creative while preserving traceability to any reused validated pattern.
