# Ads Analysis Workflow

1. Retrieve current campaign data before recommendations.
2. Separate current data from historical snapshots.
3. Compare platform attribution with commercial/last-click truth.
4. Evaluate creative and campaign performance in context.
5. Treat ROAS/CPA references as contextual unless newly validated.
6. Recommend changes only when evidence supports them.
