# Content Creation Workflow

## Context assembly
For a content task, load only the applicable combination of:
1. Nobriê brand rules
2. product context when product-specific
3. marketing/creative profile
4. channel/format references when needed
5. the specific content workflow

## Principles
- refined, confident, direct communication
- relatively short phrases and whitespace
- English for positioning/impact when appropriate
- Portuguese for explanations/details when appropriate
- no emojis or mass-retail promotional language
- scarcity and urgency must be real

Content work must not automatically load Ads, logistics, or technical integration history.
