# Conventions

## Naming
- Use descriptive, stable, lowercase paths for operational folders.
- Use Markdown for human/model-readable knowledge and procedures.
- Use YAML/JSON only when structured data materially benefits retrieval or automation.

## State labels
Tasks: `TODO`, `IN_PROGRESS`, `BLOCKED`, `WAITING_EXTERNAL`, `DONE`.

## Provenance labels
Use `CONFIRMED`, `ASSUMPTION`, `HYPOTHESIS`, `DEPRECATED`, `SUPERSEDED` where relevant.

## Dates
Use ISO dates (`YYYY-MM-DD`) for durable records.

## Decisions
Use stable decision IDs and preserve superseded decisions.
