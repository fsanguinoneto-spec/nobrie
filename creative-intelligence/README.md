# Creative Intelligence

## Purpose
Systematically learn from creatives already classified as valid without turning isolated examples into brand rules.

## Knowledge lifecycle
`OBSERVATION → HYPOTHESIS → RECURRING_PATTERN → VALIDATED_PATTERN → CREATIVE_RULE`

## Analysis dimensions
Hook, structure, first seconds, framing, rhythm, duration, text, caption, CTA, positioning, offer, storytelling, product, person/influencer, movement, scene changes, music, sound design, editing, colors, typography, graphic elements, sales pattern, retention pattern, and recurrence among winners.

## Future organization
When evidence volume justifies it, add dedicated areas for validated patterns, hypotheses, editing rules, visual rules, hooks, structures, and examples. Do not create empty directory scaffolding before those areas contain useful knowledge.

## Rule
Creative Intelligence learns from validated evidence; it does not override brand identity or current commercial/operational truth.
