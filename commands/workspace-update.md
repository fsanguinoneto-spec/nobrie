# /workspace-update

## Purpose
Synchronize meaningful work performed in a session with the canonical Nobrie workspace.

## Procedure
1. Review what was actually learned, changed, decided, completed, or blocked.
2. Classify each persistent item as rule, context, state, task, decision, reference, memory, history, output, or archive.
3. Locate the canonical source for each item.
4. Update current state, tasks, decisions, project context, memory, or references as required.
5. Remove obsolete information from current-state files without destroying meaningful history.
6. Mark changed decisions as superseded rather than silently rewriting them.
7. Check for duplicates, contradictions, stale context, orphan tasks, and broken references.
8. Update `CHANGELOG.md` only for meaningful structural or operational changes.
9. Re-check global and project context alignment.
10. Finish with a consistency audit.

## Principle
If no durable workspace fact, decision, task, state, rule, reference, or architecture changed, no persistent update is required.
