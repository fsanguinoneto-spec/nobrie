# /project-new

Create a project only when a distinct Nobrie workstream requires isolated context.

Create the minimum functional structure:
- `CONTEXT.md`
- `STATUS.md`
- `TASKS.md`
- `DECISIONS.md`
- `README.md`

Add `references/`, `stages/`, `output/`, `archive/`, `docs/`, `src/`, `data/`, `assets/`, `research/`, `automations/`, or `integrations/` only when the project actually needs them.

Projects are isolated by default.
