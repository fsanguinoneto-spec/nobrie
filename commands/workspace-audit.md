# /workspace-audit

Audit the workspace for:
- duplicate or competing canonical facts
- contradictions
- stale context
- orphaned tasks
- unregistered decisions
- broken references
- incorrect file placement
- oversized or low-density files
- redundant memory
- missing canonical sources
- stale project status
- global/project context misalignment
- history mixed into current state
- useless or temporary documentation

Report findings by severity and correct them when the required correction is clear and safe.
