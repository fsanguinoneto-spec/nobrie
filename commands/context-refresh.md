# /context-refresh

Refresh the context needed for the current task.

1. Read `AGENTS.md`.
2. Read `CONTEXT.md`.
3. Identify the relevant project and stage.
4. Load current status and tasks only when needed.
5. Load relevant decisions and references.
6. Ignore unrelated projects and historical material unless required.
7. Produce a minimum-sufficient context packet for execution.

The context packet should contain only the rules, project context, current state, relevant decisions, references, and task-specific information necessary to act accurately.
