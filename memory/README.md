# Memory

Durable memory is organized by nature rather than chronology.

## Promotion rule
Before persisting information, classify it and determine whether it is stable and reusable enough to deserve durable memory.

## Areas
- `core/` — stable foundational knowledge
- `entities/` — durable facts about people, organizations, systems, products, or other entities
- `decisions/` — durable decision knowledge
- `episodic/` — meaningful events and session records
- `summaries/` — curated summaries
- `archive/` — retired memory

Memory is not a dumping ground and is not a substitute for canonical operational files.
